# Largura Livre — guia interativo de responsividade

Projeto de Vue 3 (Vite + Vue Router + Pinia) sobre responsividade.

## Como rodar

```bash
npm install
npm run dev      # abre em http://localhost:5173
npm run build    # gera a pasta dist/ para publicar
```

## Estrutura

- `src/assets/tokens.css` — variáveis CSS (cores, espaços, fontes)
- `src/components/SecaoGuia.vue` — molde das 4 partes de cada seção
- `src/components/labs/` — laboratórios interativos
- `src/views/` — uma tela por seção
- `src/router/index.js` — rotas com carregamento sob demanda
